# ParkingFinder

ParkingFinder is a React application that helps drivers locate and reserve parking spaces in Richmond, Virginia. The app combines an interactive map with reservation management to make parking simple.

## Project Overview

ParkingFinder allows users to search for available parking, complete a guided reservation flow, and view a map and chart of parking availability around Richmond.

## Setup

1. **Install dependencies**

   ```bash
   npm install
   ```

2. **Start the development server**

   ```bash
   npm start
   ```

   The application runs at [http://localhost:3000](http://localhost:3000) and automatically reloads as you edit the code.

3. **Run tests**

   ```bash
   npm test
   ```

4. **Create a production build**

   ```bash
   npm run build
   ```

## Usage

1. Use the search tools or map to find open parking spots.
2. Select a location to see details and follow the reservation steps.
3. View the Richmond map and accompanying chart to explore parking trends across the city.

## Features

- 🔍 Search for parking spaces by area or point of interest.
- 📝 Step-by-step reservation flow for confirming a parking spot.
- 🗺️ Interactive Richmond map with a chart showing local parking statistics.
